# 두잇 동아리(창의적 체험활동 · 동아리활동 특기사항) — 누적 지시

> **산출물은 판본 폴더에 있다.** `results/<연도>_<과목>/<판본>/students.json`·`결과.html`·`결과.xlsx`·`교과기초자료.xlsx` 한 벌이고, 그 판본을 만들 때 쓴 스크립트와 중간 파일은 그 아래 `작업/`에 있다. `원자료.json`은 판본 위(과목 폴더 바로 아래)에 둔다. 어느 판본이 최종인지는 과목 폴더의 `README.md`에 적혀 있다.

- **산출물 폴더**: `results/2026_두잇동아리/`
- **맞춤 프롬프트 없음**: 이 작업은 백지에서 쓰는 것이 아니라 **이미 작성된 특기사항을 규정·문체에 맞게 교정**하는 성격이다.
  원자료(hwpx)에 학생별 특기사항이 완성돼 있고, 우리가 하는 일은 분량·표기·문체 위반을 잡는 것이다.
- **분량**: 1450~1500바이트 (동아리활동 특기사항 500자 = 1500바이트). 교과 세특과 같은 기준.
- **교정 방침(사용자 확인 2026-08-06)**: **사실과 활동 순서는 원문 그대로 둔다.** 새 사실을 넣거나 활동을 지어내지 않고,
  분량 초과분은 *같은 말을 두 번 하는 자리*를 걷어내 맞춘다. 미달이면 감탄 어휘로 뭉뚱그린 자리를 사실 진술로 풀어 채운다.
- **자주 나오는 위반 4종** (2026 3학년 5명 실측: 쉼표 15건·가운뎃점 2개·감탄 어휘 4건·오타 1건):
  - 연결어미 뒤 쉼표 (`~하고,` `~하며,` `~으나,`) → 0이어야 함
  - 가운뎃점 나열 (`수집·분석`, `벽·문`) → '와/과'·쉼표·풀어쓰기로 대체
  - 감탄 어휘 (`인상적임`·`돋보임`·`뛰어남`·`우수함`) → 사실 진술로 교체
  - 기호 나열 (`측정-분석-제어-통신의 흐름`) → 말로 풀어쓰기
- **도구·라이브러리 표기는 통일하지 않는다**: 학생마다 `Python`/`파이썬`, `Wi-Fi`/`와이파이`가 섞여 있어도 원 작성자의 표기를 존중한다.
  (사용자가 반 전체 통일을 원하면 그때 반영 — 2026-08-06 기준 미요청)
- **원본 보존**: 교정 결과는 `평가문`을 덮지 않고 `평가문_검토본`으로 추가한다(스킬 공통 규약).
- **판본 두 종을 나란히 낸다(사용자 요청 2026-08-06)**: 같은 원자료로 ① **교정본**(원문 구조 유지 + 규정 위반만 수정)과
  ② **재작성본**(v2 골격으로 백지에서 다시 씀)을 **각각 별도 파일**로 만든다. 하나를 다른 하나로 대체하지 않는다.
  - 교정본: `students.json` · `결과.html` · `품질수정_변경내역.md`
  - 재작성본: `students_재작성.json` · `결과_재작성.html` · `재작성_설계메모.md` (생성 스크립트 `write_new.js`)
- **재작성 시 확인된 함정**: 초안에서 다섯 중 넷의 첫 문장이 `~하지 않고 ~` 한 골격으로 쏠렸다.
  첫 문장은 다 쓴 뒤 **모아 읽어 골격과 종결 동사를 갈라야** 한다(v2의 통로 배분만으로는 안 걸러진다).
  또 재작성은 원문에 없는 서술이 섞이기 쉽다(심리 묘사·수행 주체·시간 조건). 다 쓴 뒤 원자료와 문장 단위로 대조한다.
- **활동명 미확정**: 원자료가 산문이라 공식 활동명이 없어 원문 표현으로 고정했다
  (`와이파이 신호 강도 측정 및 히트맵 시각화 프로젝트` / `엔트리 블록코딩 활동` / `진로탐구보고서`).
  학교 정식 명칭을 알게 되면 바꾼다.

## 이 폴더의 Node 스크립트 (Python 부재 대응)
작업 PC에 Python이 설치돼 있지 않아 스킬의 파이썬 스크립트를 실행할 수 없다.
**공용 스크립트는 수정하지 않고**, 같은 계산 규칙을 옮긴 Node 스크립트를 `results/2026_두잇동아리/`에 두었다.

| 스크립트 | 대응 | 역할 |
|---|---|---|
| `tools.js` | `byte_count.py` + `comma_check.py` | 바이트 계산(한글3/엔터2/그외1), 연결어미 뒤 쉼표·가운뎃점·감탄 어휘 점검 |
| `import_hwpx.js` | — | hwpx(ZIP)를 기본 모듈만으로 풀어 `students.json` 생성 |
| `apply_review.js` | — | 교정본을 `평가문_검토본`으로 추가 |
| `check.js` | `byte_count.py --json` | 판본별 일괄 검수 (`node check.js students.json 평가문_검토본`) |
| `write_new.js` | — | 재작성본을 `students_재작성.json`으로 생성(평가문=원문 / 평가문_검토본=재작성본) |
| `build_html.js` + `template.html` | `build_html.py` | 원본/검토본 나란히 + 변경 강조 HTML. difflib 대신 LCS opcode. **판본 이름과 변경 강조 기본값을 인자로 받는다** (`--labelA --labelB --badgeChg --chgLabel --optBoth --onlyChg --diff off`) — 전면 재작성 비교에서는 강조를 꺼 둔다 |
