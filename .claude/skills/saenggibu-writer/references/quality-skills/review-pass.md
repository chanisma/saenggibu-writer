# 별도 검토 패스 (독립 서브에이전트 품질 검토)

평가문은 **작성한 컨텍스트에서 스스로 승인하지 않는다.** 배치 작성과 내재화 보정이 끝나면,
**독립 서브에이전트**에게 grammar-checker·humanizer·style-guide + 세특 가드레일로 검토를 맡기고,
돌아온 지적을 **저자(메인)가 등가·의미보존 원칙으로 반영**한다. (내재화 보정만으로는 style-guide의
반 전체 쏠림·맞춤법 정밀 오류를 놓치기 쉽다 — 실제로 얕은 grep 린트는 맺음말 쏠림을 못 잡는다.)

## 언제 · 어떻게
- **시점**: 4단계 배치 작성 + 1차 내재화 보정 + 바이트 1차 검수 후.
- **사용자 확인 게이트**: 토큰·시간이 드므로 **먼저 사용자에게 물어보고** 실행한다.
  예: "정식 품질 검토 패스(독립 서브에이전트)를 돌릴까요? 문법·자연스러움·반 전체 일관성을 봅니다."
- **독립 실행**: `Agent`(general-purpose 등)로 **검토만** 시킨다(파일 수정 금지, 지적 목록만 반환).
  자기검토·자기승인 방지가 목적이므로 메인이 직접 재작성 판단을 겸하지 않는다.
- **반영**: 돌아온 지적 중 **필수(등가·의미보존)**를 먼저 반영하고, 선택은 과교정 위험을 보며 취사.
  반영 후 `byte_count.py --json ... --write`로 **바이트 재검증**, 그다음 산출물 재생성.

## 서브에이전트 프롬프트 템플릿
`{DIR}` = `results/<연도>_<과목>`, `{SKILL}` = 이 스킬 폴더. 그대로 채워 `Agent`에 넘긴다.

```
너는 고등학교 생활기록부 세특 평가문의 **품질 검토자**다. 작성은 이미 끝났고, 너는 **검토만** 한다
(파일을 직접 고치지 말고 지적 목록만 반환). 아래 세 축으로 점검하고 **구체적·최소 수정 제안**을 돌려줘.

## 읽을 파일
1. 검토 대상: `{DIR}/students.json` → 각 학생 `평가문` 필드.
2. 규칙·가드레일(먼저 읽기):
   - `{SKILL}/references/quality-skills/README.md`  ← 세특 가드레일(최우선)
   - `{SKILL}/references/quality-skills/grammar-checker/references/`  (rules.md, common-errors.md)
   - `{SKILL}/references/quality-skills/humanizer/references/`  (patterns 6종)
   - `{SKILL}/references/quality-skills/style-guide/references/`  (7 카테고리)

## 세 축 — **각 축의 글로벌 Skill을 실제로 호출한다** (문서만 읽고 눈대중 금지)
각 축에서 `Skill` 도구로 해당 스킬(`grammar-checker`·`humanizer`·`style-guide`)을 **직접 실행**해 분석하라. 참고 문서(`references/`)는 판정 기준일 뿐, 실행을 대체하지 않는다. 실행 결과를 세특 가드레일에 맞춰 취사해 지적으로 정리한다.
1. **grammar-checker(글마다)**: `Skill: grammar-checker`로 맞춤법(되/돼·-ㄴ지/-는지·안/않), 의존명사·보조용언 띄어쓰기, 조사, 어미, 구두점 검사.
2. **humanizer(글마다) — 반드시 실제 호출**: `Skill: humanizer`로 40패턴 S1/S2/S3 분석. 특히 세특에서 잦은 것: 쉼표 과다, **명사화 과다·동사 빈곤(품사 다양성)**, 번역투(에 대해/에 대한/을 통해/되어진다/에 의해/있어서), `~적 N` 체인, **3박자·구조 단조로움**. 검출된 패턴을 심각도와 함께 보고하고, 세특 가드레일(명사형 종결·의미 보존)에 맞는 등가 수정만 제안.
   - **쉼표·가운뎃점 점검은 필수(생략 불가)**: humanizer 패턴 1(쉼표 밀도)·3(연결어미 뒤 쉼표)과 **가운뎃점(·) 나열**은 세특의 대표 AI 흔적이므로 반드시 짚는다. 눈대중하지 말고 `python {SKILL}/scripts/comma_check.py --json {DIR}/students.json` **측정값**을 검토 결과에 포함하라. 판정 기준: **연결어미 뒤 쉼표(패턴 3)와 가운뎃점은 모두 0**을 목표(있으면 학생별로 지적), 밀도>0.5(패턴 1)는 남은 쉼표가 목록·조사·도입 동격처럼 꼭 필요한지 확인해 불필요하면 지적. 목록 쉼표(`A와 B, C`)·조사 뒤(`~에서,`/`~로,`)·도입 동격구(`~한 학생으로,`)는 정상이니 제거 대상이 아니다. **가운뎃점으로 여러 요소를 나열한 곳**(`A·B·C`)은 '와/과'·쉼표·풀어쓰기로 바꾸도록 지적한다.
3. **style-guide(반 전체)**: `Skill: style-guide`로 용어 통일(영문 `AI` 노출 0, 활동 명칭 통일), **첫문장·맺음말·문장 골격의 분산**(같은 표현 쏠림 지적).

## 세특 가드레일 (세 스킬 기본값보다 항상 우선)
- 모든 문장 **명사형 종결**(~함/~임/~음/~감/~봄). `~합니다/~이다/~했다`로 바꾸자는 제안 금지.
- 간접인용 안긴문장(~다는 생각/~다고 봄/대비됨)은 정상 — 오탐 금지(문장 끝만 명사형인지 본다).
- 주어 '학생은/이 학생' 되살리기 금지. 한 문단 유지.
- **과교정 금지**: 의미·근거·인과·수치·고유명사 보존. 이미 자연스럽고 일관되면 그대로 두라고 명시.
- 분량 민감: 각 글은 목표 바이트에 이미 맞춰짐. 제안은 **길이를 크게 바꾸지 않는 등가 치환** 위주로,
  늘/줄면 표시(+n자/-n자). 근거를 바꾸는 제안 금지.
- 코드/변수명/URL/개인취향 소재 노출 금지, 부정·예측 평가 금지(이미 준수 여부 확인).

## 출력 형식 (최종 반환값 = 데이터, 인사말 없이)
[반 전체(style-guide) 소견] 첫문장 분산 / 맺음말 분산 / 용어·골격 일관성
[쉼표·가운뎃점 점검(필수)] comma_check.py 측정: 연결어미 뒤 쉼표 총건수(0 목표)·가운뎃점 총개수(0 목표)·과다 판정 학생 수
[학생별 지적] 학번 이름 | 축 | 현재구절 | 제안 | 길이영향 | 이유(한 줄)   ← 실제 문제만
[총평] 실제 수정 필요 건수(필수 vs 선택), 전반 판정(양호/보정 필요)
파일에서 실제 확인되는 것만. 확신 없으면 '선택'. 사소한 취향으로 과도한 리라이트 요구 금지.
```

## 반영·기록 (필수) — **덮어쓰지 않고 추가한다**
- **`평가문`(원본)은 절대 고치지 않는다.** 반영 결과는 `students.json`의 **`평가문_검토본`** 필드에 담는다.
  수정할 것이 없는 학생도 검토를 거쳤다면 같은 문장을 넣어 "검토했으나 수정 없음"을 남긴다.
  필드 규약은 `{SKILL}/scripts/evaltext.py`에 있고 빌드 스크립트가 이를 따른다.
- **기존 산출물 파일도 갈아엎지 않는다.**
  - `결과.html`·`결과.xlsx`는 재생성해도 **원본과 검토본을 나란히** 담으므로 원본 판본이 사라지지 않는다
    (HTML 상단 `보기`에서 *나란히 / 원본만 / 검토본만*, 검토본 칸에 `수정`/`동일` 배지).
  - HTML은 **바뀐 곳을 색으로 강조**한다(원본 쪽 빠진 말 = 취소선, 검토본 쪽 들어온 말 = 녹색).
    `변경 강조`·`수정된 학생만` 체크박스로 켜고 끄며, 이 화면이 곧 **사용자가 검토 반영을 승인하는 자리**다.
    반영 결과를 보고할 때 이 화면을 근거로 안내하라 — 무엇이 바뀌었는지 말로만 설명하지 않는다.
  - 업로드 xlsx는 한 판본만 들어가므로 **다른 파일명으로 따로** 뽑는다:
    `build_gwagi.py ... --text 평가문_검토본 → 교과기초자료_검토본.xlsx` (원본 파일은 그대로 둔다).
- **원문→수정 변경 내역**을 `{DIR}/품질수정_변경내역.md`로 저장한다:
  ① 구절별 표(학번·이름·축·`원문`→`수정`·길이영향·사유) ② 학생별 전문 비교(원본 vs 검토본, 바이트 포함).

## 반영 후 정량 체크
- **쉼표·가운뎃점(필수)**: `comma_check.py --json {DIR}/students.json` → 연결어미 뒤 쉼표 0건·가운뎃점 0개 확인. 연결어미 뒤 쉼표는 `--clean --write`로 정리, 가운뎃점은 '와/과'·쉼표·풀어쓰기로 손본 뒤 재측정.
- **바이트**: `byte_count.py --json {DIR}/students.json --write` → 완료 1450~1500·초과 0(과목 규칙대로). **쉼표를 정리했으면 바이트가 줄므로 반드시 재검증**하고 미달은 등가 보정.
- 영문 `AI` 노출 0, 첫문장·맺음말 분포가 한쪽으로 쏠리지 않는지, 번역투 마커 소수.
- 반영이 근거·수치·인과를 바꾸지 않았는지(과교정 여부) 최종 확인.
